# 레벨 에디터 사용법 (기획자용)

Unity 메뉴 **RatLoop > 레벨 에디터** (단축키 `Ctrl+Shift+L`)를 열면 이 창 하나로 레벨을 만들고 테스트할 수 있습니다.
하이어라키와 인스펙터는 쓰지 않아도 됩니다.

## 레벨 목록 화면

- 게임에 나오는 순서대로 레벨이 카드로 보입니다. `▲` `▼` 로 순서를 바꾸면 스테이지 번호도 바뀝니다.
- `빼기` 는 목록에서만 빼고 레벨 파일은 남깁니다. 목록에 없는 레벨은 따로 보이고 `목록에 추가` 로 다시 넣습니다.
- 맨 아래 `새 레벨 만들기` 에 이름을 쓰고 `만들고 열기` 를 누르면, 바닥, 시작 위치, 치즈가 들어 있는 레벨이 목록 맨 뒤에 생깁니다.

## 편집 화면

맨 위 줄: `‹ 목록`(목록으로 돌아가기), `저장`(저장 안 된 변경이 있으면 노란색), `▶ 테스트 플레이`.

바로 아래의 색 막대는 문제 검사 결과입니다. **문제 없음**(초록), **경고**(노랑), **오류**(빨강)이 자동으로 갱신되고, 누르면 검사 화면으로 갑니다.
`레벨 설정` 을 펼치면 레벨 이름, 제한 시간, 리플레이 횟수, 카메라 줌을 바꿀 수 있습니다.

그 아래 모드 버튼을 고르면 해당 도구가 씬 화면에서 바로 켜집니다. 씬 화면 왼쪽 위에는 지금 쓰는 도구와 조작법이 표시됩니다.
어느 모드에서든 `Esc` 를 누르면 도구가 꺼지고 '선택·이동' 모드로 돌아갑니다. 실행 취소는 `Ctrl+Z` 이고, 한 번 칠하거나 놓은 것은 한 번에 취소됩니다.

### 선택·이동

- 씬 화면에서 프롭을 클릭해 고르고 끌어서 옮깁니다. (`W`: 이동, `E`: 회전)
- 고른 프롭의 값(질량, 마찰, 물 크기 등), 위치, 각도, 좌우 뒤집기, 지우기가 창에 나옵니다. `기본값으로 되돌리기` 로 원래 값으로 돌릴 수 있습니다.
- 아래 `이 레벨에 있는 프롭` 목록에서 이름을 누르면 그 프롭으로 이동합니다.

### 타일

1. **어디에 칠할까요?** 에서 `지형`(밟고 부딪힘), `뒤 장식`, `앞 장식`(둘 다 통과) 중 하나를 고릅니다.
2. 팔레트는 타일 이미지 파일의 배치 그대로 보입니다. 타일 하나를 클릭하거나, **끌어서 영역을 골라** 여러 칸을 한 번에 고를 수 있습니다.
   여러 칸짜리 타일(기둥 등)을 영역으로 고르면 **고른 모양 그대로** 찍힙니다. 찍히는 위치는 마우스 칸이 스탬프의 왼쪽 아래입니다.
3. 씬 화면을 클릭하거나 끌어서 칠합니다. `Shift` 를 누르고 칠하거나 `지우개` 를 고르면 지워집니다.

### 프롭

- 위의 검색칸과 분류(물리, 고정, 장식, 로프, 물, 투명벽, 기믹)로 찾고, 프롭을 클릭하면 선택됩니다. 다시 누르면 선택이 풀립니다.
- 씬 화면을 클릭하면 놓입니다. `놓는 간격` 은 0.25칸, 0.5칸, 1칸 중에서 고릅니다.
- **물** 과 **투명벽** 은 칸 단위 영역입니다. 놓은 뒤 '선택·이동' 에서 가로/세로 칸 수를 바꾸거나, 씬 화면의 손잡이(오른쪽, 위쪽, 오른쪽 위 모서리)를 끌어서 크기를 바꿉니다.
- **투명벽** 은 게임에서는 보이지 않고 에디터에서만 반투명하게 보입니다. 플레이어와 고스트가 지나가지 못합니다.
  `물체도 막기` 를 켜면 박스, 공 같은 물체도 지나가지 못합니다. (켜면 붉은색, 끄면 보라색으로 보입니다)

### 시작·치즈

- 시작 위치와 치즈는 씬 화면에서 늘 초록색(시작), 노란색(치즈) 원으로 표시됩니다. 도구가 꺼져 있을 때 **원을 끌어서** 옮길 수 있습니다.
- 이 모드에서 `씬 화면을 클릭해서 옮기기` 를 누르면 클릭하는 자리로 옮겨지고, X, Y 숫자로 정확한 위치를 넣을 수도 있습니다.

### 검사

- **빨간 오류**가 있으면 테스트 플레이를 할 수 없습니다. (시작 위치나 치즈가 없음, 질량 0 등)
- **노란 경고**는 확인만 하면 됩니다. (지형에 박힌 프롭, 겹친 프롭, 시작 위치 아래에 땅 없음 등)
- `찾기` 를 누르면 문제가 있는 프롭으로 이동합니다.

## 개발자용

- 새 프롭: `LevelProp` 을 상속한 컴포넌트가 붙은 프리팹을 만들고 `Assets/_Project/Data/PropCatalog` 에 한 줄 추가합니다.
- 칸 단위 영역 프롭은 `IAreaProp` 을 구현하고 `width`, `height` 필드를 두면 팔레트 놓기와 크기 손잡이가 같이 동작합니다. (`AreaHandles`)
- 기획자에게 보여줄 값에는 `[PlannerField("이름")]` 을 붙입니다. 에디터 창과 인스펙터에 자동으로 나타납니다.
- 레벨 전체 검사는 `LevelRoot.Validate`, 프롭 하나의 검사는 각 프롭의 `Validate` 를 고칩니다.
- 에디터 창은 `LevelEditorWindow.cs`(화면)와 `LevelEditorWindow.Scene.cs`(씬 도구), `TilePaletteView.cs`(타일 팔레트)로 나뉘어 있습니다.
