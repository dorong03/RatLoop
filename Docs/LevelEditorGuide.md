# 레벨 에디터 사용법 (기획자용)

Unity 메뉴 **RatLoop > 레벨 에디터**(단축키 `Ctrl+Shift+L`)를 열면 이 창 하나로 레벨을 만들고 테스트할 수 있어요.
하이어라키와 인스펙터는 쓰지 않아도 돼요.

## 화면 구성

모든 창은 같은 구성을 써요.

| 위치 | 들어 있는 것 |
|---|---|
| 맨 위 | 창 전체에 해당하는 버튼 (목록으로, 저장, 테스트 플레이) |
| 가운데 | 지금 탭에 필요한 것만 보여요. 길어지면 스크롤돼요. |
| 맨 아래 (고정) | 지금 할 수 있는 일 안내, 또는 `만들기` 같은 주요 버튼 |

- 관련된 기능은 한 줄이나 한 카드에 모여 있어요. 예를 들어 `격자`와 `놓는 간격`은 놓는 도구마다 같은 줄에 있어요.
- 목록에서 빼기, 삭제처럼 되돌리기 어려운 동작은 `⋮` 메뉴 안에 있어요.

## 레벨 목록 화면

- 게임에 나오는 순서대로 레벨 카드가 보여요. `▲` `▼`로 순서를 바꾸면 스테이지 번호도 바뀌어요.
- `열기`로 레벨을 편집해요.
- `⋮` 메뉴
  - `게임 목록에서 빼기`: 스테이지 선택 화면에서만 사라지고 파일은 남아요. '게임 목록에 없는 레벨'에 따로 보이고 `목록에 추가`로 다시 넣을 수 있어요.
  - `레벨 삭제…`: 파일을 휴지통으로 옮겨요. 실수로 지웠다면 휴지통이나 Git에서 되살릴 수 있어요.
- 맨 아래 **새 레벨** 줄에 이름을 쓰고 `만들기`를 누르면 바닥, 시작 위치, 치즈가 놓인 레벨이 목록 맨 뒤에 생겨요.
- 게임의 스테이지 선택 화면에는 **게임 목록에 있는 레벨만** 나와요. 목록에 없는 레벨을 열면 편집 화면 위에 `게임 목록에 추가` 버튼이 보여요.
- 스테이지는 앞 스테이지를 깨야 열려요. 테스트할 때는 `테스트용 진행도`를 펼쳐서 `모든 스테이지 열기`나 `처음 상태로`를 눌러요.

## 편집 화면

- **맨 위 줄**: `‹ 목록`, 레벨 이름, `저장`(바뀐 내용이 있으면 파란색), `테스트 플레이`.
- **레벨 상태 줄**: 왼쪽은 검사 결과예요. `문제 없음`, `경고`, `오류`가 자동으로 바뀌고, 누르면 검사 탭으로 가요.
  오른쪽 `레벨 설정 ▾`을 누르면 레벨 이름, 제한 시간, 리플레이 횟수, 카메라 줌을 바꿀 수 있어요.
- **탭**: `선택` `타일` `프롭` `시작·치즈` `검사`. 탭을 고르면 그 도구가 씬 화면에서 바로 켜져요.
- 씬 화면 왼쪽 위와 창 맨 아래에 지금 도구와 조작법이 보여요.
- 어느 탭에서든 `Esc`를 누르면 도구가 꺼지고 `선택` 탭으로 돌아가요.
- 실행 취소는 `Ctrl+Z`예요. 한 번 칠하거나 놓은 것은 한 번에 취소돼요.

### 선택

- 씬 화면에서 프롭을 클릭해서 고르고 끌어서 옮겨요. (`W` 이동, `E` 회전)
- 고른 프롭의 값은 두 묶음으로 나뉘어요.
  - **공통 설정**: 크기, 무게, 마찰, 튕김, 부력, 물살 같은 값이에요. 바꾸면 그 프롭의 종류(프리팹)가 바뀌어서
    **이미 놓은 것과 다른 레벨의 같은 프롭까지 함께 바뀌어요.** 같은 프롭은 항상 같은 값을 써요.
  - **이 프롭만**: 물과 투명벽의 칸 수, 로프 마디 수, 위치, 각도, 좌우 뒤집기처럼 놓은 자리마다 다른 값이에요.
- 물리, 고정, 장식 프롭은 공통 설정의 `크기`(1이 원래 크기)를 바꿀 수 있어요. 그림과 부딪히는 모양이 함께 바뀌어요.
  같은 그림을 다른 크기로 함께 쓰려면 `+ 새 프롭`으로 다른 종류를 하나 더 만들어 주세요.
- 어떤 프롭만 공통 설정과 값이 다르면 노란 경고가 보여요. `공통 설정으로 되돌리기`를 누르면 다시 같은 값을 써요.
- 아래 `이 레벨의 프롭` 목록에서 이름을 누르면 씬 화면에서 그 프롭으로 이동해요.

### 타일

1. 위 카드에서 **칠할 곳**(`지형`, `뒤 장식`, `앞 장식`)과 **도구**(`칠하기`, `지우개`)를 골라요.
   지형은 밟고 부딪히고, 장식은 부딪히지 않아요.
2. 팔레트는 타일 이미지의 배치 그대로 보여요. 타일 하나를 클릭하거나, **끌어서 여러 칸을 함께** 고를 수 있어요.
   여러 칸을 고르면 **고른 모양 그대로** 칠해져요. 마우스가 있는 칸이 그 모양의 왼쪽 아래예요.
3. 씬 화면에 칠해질 모양이 흐리게 미리 보여요. 클릭하거나 끌어서 칠하고, `Shift`를 누른 채 칠하면 지워져요.

새 타일 이미지는 팔레트 오른쪽 위 `+ 타일 이미지 추가`로 넣어요. 메뉴에서 한 칸의 크기(기본 16픽셀)를 고른 뒤 PNG를 골라요.
자세한 방법은 `Docs/AddingContent.md`를 봐 주세요.

### 프롭

- 위쪽 검색칸과 분류(물리, 고정, 장식, 로프, 물, 투명벽, 기믹)로 찾고, 프롭을 클릭하면 골라져요. 다시 누르면 선택이 풀려요.
- 고른 프롭 아래에 **공통 설정**이 보여요. 놓기 전에 여기서 값을 정해도 되고, 바꾸면 이미 놓은 것과 다른 레벨에도 함께 적용돼요.
- 씬 화면에 놓일 모습이 흐리게 미리 보이고, 클릭하면 그 자리에 놓여요. `놓는 간격`은 0.25칸, 0.5칸, 1칸 중에서 골라요.
- **로프**는 마디 수를 바꾸면 편집 화면에서 바로 길이가 바뀌어 보여요. 위쪽 고정점이 매달리는 기준이에요.
- 원하는 프롭이 없으면 `+ 새 프롭`으로 그림에서 바로 만들 수 있어요. (`Docs/AddingContent.md`)
- **물**과 **투명벽**은 칸 단위 영역이에요. 놓은 뒤 `선택` 탭에서 가로·세로 칸 수를 바꾸거나, 씬 화면의 손잡이를 끌어서 크기를 바꿔요.
  오른쪽 점은 가로, 위쪽 점은 세로, 오른쪽 위 네모는 둘 다예요.
- **물**은 몸이 `빠지는 깊이`(기본 35%) 이상 잠기고 몸 중심이 물 위에 있을 때만 빠져요. 물가에 살짝 걸친 정도로는 빠지지 않아요.
- **투명벽**은 게임에서는 보이지 않고 에디터에서만 반투명하게 보여요. 두 종류가 있어요.
  - `투명벽 (캐릭터만 막기)`: 쥐와 고스트만 막고 물체는 지나가요. (보라색)
  - `투명벽 (물체도 막기)`: 박스, 공 같은 물체까지 모두 막아요. (붉은색)

### 시작·치즈

- 시작 위치와 치즈는 씬 화면에 늘 초록색(시작), 노란색(치즈) 원으로 보여요. 도구가 꺼져 있을 때 **원을 끌어서** 옮길 수 있어요.
- 이 탭에서 `클릭해서 옮기기`를 누르면 클릭하는 자리로 옮겨지고, X, Y 숫자로 정확한 위치를 넣을 수도 있어요.

### 검사

- **빨간 오류**가 있으면 테스트 플레이를 할 수 없어요. (시작 위치나 치즈가 없음, 무게 0 등)
- **노란 경고**는 확인만 하면 돼요. (지형에 박힌 프롭, 겹친 프롭, 시작 위치 아래에 땅 없음 등)
- `찾기`를 누르면 문제가 있는 프롭으로 이동해요.

## 개발자용

- 새 프롭: `LevelProp`을 상속한 컴포넌트가 붙은 프리팹을 만들고 `Assets/_Project/Data/PropCatalog`에 한 줄 추가합니다.
- 칸 단위 영역 프롭은 `IAreaProp`을 구현하고 `width`, `height` 필드를 두면 팔레트 놓기와 크기 손잡이가 같이 동작합니다. (`AreaHandles`)
- 기획자에게 보여줄 값에는 `[PlannerField("이름")]`을 붙입니다. 에디터 창과 인스펙터에 자동으로 나타납니다.
  이름과 `[Tooltip]`은 기획자가 읽으므로 해요체로 짧게 씁니다.
- 레벨 전체 검사는 `LevelRoot.Validate`, 프롭 하나의 검사는 각 프롭의 `Validate`를 고칩니다. 메시지도 해요체로 씁니다.
- 에디터 창은 `LevelEditorWindow.cs`(화면), `LevelEditorWindow.Scene.cs`(씬 도구), `TilePaletteView.cs`(타일 팔레트)로 나뉘어 있습니다.
- 버튼 색, 카드, 바닥 줄 같은 화면 스타일은 `EditorUI.cs`에서만 정합니다. 새 창이나 기능도 이 도우미를 써서 같은 모양으로 만듭니다.
