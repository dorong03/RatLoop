# 레벨 에디터 사용법 (기획자용)

Unity 메뉴 **RatLoop > 레벨 에디터** (단축키 `Ctrl+Shift+L`)를 열면 이 창 하나로 레벨을 만들고 테스트할 수 있습니다.
하이어라키와 인스펙터는 쓰지 않아도 됩니다.

## 레벨 목록 화면

- 게임에 나오는 순서대로 레벨이 보입니다. `▲` `▼` 로 순서를 바꾸면 스테이지 선택 화면의 순서도 바뀝니다.
- `빼기` 는 목록에서만 빼고 레벨 파일은 남깁니다. 목록에 없는 레벨은 아래에 따로 보이고 `목록에 추가` 로 다시 넣습니다.
- `새 레벨 만들기` 에 이름을 쓰고 `만들기` 를 누르면 바닥, 시작 위치, 치즈가 들어 있는 레벨이 목록 맨 뒤에 생깁니다.

## 편집 화면

맨 위 버튼

| 버튼 | 하는 일 |
|---|---|
| 저장 | 레벨을 저장하고 세이프티 체크를 실행합니다. |
| 테스트 플레이 | 저장한 뒤 이 레벨을 바로 플레이합니다. 플레이를 멈추면 편집 화면으로 돌아옵니다. |
| 화면 맞추기 | 씬 화면을 레벨 전체가 보이게 맞춥니다. |
| 레벨 목록 | 목록 화면으로 돌아갑니다. |

**레벨 설정**: 레벨 이름, 제한 시간, 리플레이 횟수, 카메라 줌(보통/넓게).

### 타일 탭

1. 칠할 곳을 고릅니다. **지형**은 밟고 부딪히는 땅과 벽, **뒤 장식**과 **앞 장식**은 그림만 있고 지나갈 수 있습니다.
2. 타일을 클릭하고 씬 화면에서 왼쪽 버튼으로 칠합니다. `Shift` 를 누른 채 칠하면 지워집니다. `Esc` 로 멈춥니다.

### 프롭 탭

1. 위의 분류(물리, 고정, 장식, 로프, 물, 기믹)를 고르고 프롭을 클릭합니다.
2. 씬 화면을 클릭하면 그 자리에 놓입니다. `칸 맞춤` 으로 놓는 간격을 정합니다. `Esc` 로 멈춥니다.
3. 놓은 프롭을 옮길 때는 씬 화면에서 끌어서 옮깁니다. (`W` 키: 이동 도구)

**물**: 놓은 뒤 '선택한 것' 탭에서 가로/세로 칸 수를 바꾸거나, 씬 화면의 파란 손잡이를 끌어서 크기를 바꿉니다.
그림, 판정, 수면 높이가 같이 맞춰집니다.

### 선택한 것 탭

씬 화면에서 프롭을 클릭하면 그 프롭의 값을 바꿀 수 있습니다.

- 물리 프롭: 질량, 중력 배율, 이동/회전 저항, 마찰, 튕김, 회전 고정, 물에 뜨는 정도
- 물: 크기, 부력, 물속 저항, 물살, 익사 시간
- 로프: 마디 수, 마디 무게, 흔들림 저항
- 각도 조절, 좌우 뒤집기, 지우기
- `기본값으로 되돌리기` 를 누르면 그 프롭의 원래 값으로 돌아갑니다.

### 세이프티 체크 탭

- **빨간 오류**가 있으면 테스트 플레이를 할 수 없습니다. (시작 위치나 치즈가 없음, 질량 0 등)
- **노란 경고**는 확인만 하면 됩니다. (지형에 박힌 프롭, 겹친 프롭, 시작 위치 아래에 땅 없음 등)
- `보기` 를 누르면 문제가 있는 프롭으로 이동합니다.

## 개발자용

- 새 프롭: `LevelProp` 을 상속한 컴포넌트가 붙은 프리팹을 만들고 `Assets/_Project/Data/PropCatalog` 에 한 줄 추가합니다.
- 기획자에게 보여줄 값에는 `[PlannerField("이름")]` 을 붙입니다. 에디터 창과 인스펙터에 자동으로 나타납니다.
- 레벨 전체 검사는 `LevelRoot.Validate`, 프롭 하나의 검사는 각 프롭의 `Validate` 를 고칩니다.
